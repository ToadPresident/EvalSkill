# EvalSkill

Reusable skills for evidence-grounded evaluation research.

## Scientific Benchmark Validity v4

[Skill](skills/scientific-benchmark-validity/SKILL.md) · [English report template](skills/scientific-benchmark-validity/references/report-template.md) · [Rule provenance](skills/scientific-benchmark-validity/references/rule-provenance.md)

This skill applies Measurement to Meaning (M2M) to specific claims about scientific benchmarks. It produces a complete sourced analysis across content, criterion, construct, external and consequential validity. Reports default to English; explicit Chinese or bilingual requests are supported.

Provide a benchmark name, paper or link. The skill distinguishes framework principles from implementation choices, checks material facts and explains qualitative judgments. It does not compute a universal benchmark validity score.

Copy the complete skill directory into your agent's configured skills directory, or provide its SKILL.md path explicitly. Keep the references and agent metadata with the entrypoint.

This repository contains reusable skill material only. Source papers, benchmark datasets, generated reports, local paths and run records are not included. Version 4 is retained in Git history for comparison with later versions.

Method source: [Measurement to Meaning](https://arxiv.org/abs/2505.10573v4). This is an independent implementation, not an official M2M release.
