# Changelog

## 5.1.0 - 2026-10-15

- Added one-command installation for six coding-agent targets, manual installation, pinned-release instructions and a demonstration guide.
- Added real-report evidence-reference checks via `--report`, with explicit uninspected and unsupported-marker outcomes.
- Preserved all-ungraded systems/items as counts with undefined scores; checked conflicting condition declarations and malformed profile/registry input.
- Added optional versioned task inventories to detect tasks absent from all response rows.
- Deferred reference loading to relevant steps, preserved conditions in compact judgment tables, and required inspection of available decisive study outcomes.
- Added 15 synthetic regressions (37 total) and installation/byte-identity CI across Linux, macOS and Windows.
- Kept v5.0.0 and its raw case reports unchanged. New full-report and comprehension effects have not been measured; see [development priorities](docs/DEVELOPMENT.md).

## 5.0.0 - 2026-10-15

- Added a measurement profile and explicit routing from claim/evidence requirements to eligible analyses.
- Added standard-library CSV auditing, binary response/repetition diagnostics, and conditional paired task/cluster bootstrap intervals.
- Added evidence-record integrity checks while keeping factual and inferential review distinct.
- Added explicit reported/computed/failed/unavailable/simulation statuses and evidence-to-claim result interpretation.
- Extended the complete English report template without changing M2M's five dimensions or qualitative labels.
- Added 22 synthetic software tests. IRT, factor analysis and G-theory remain guidance, not executable bundled capabilities.
- Preserved v4 in Git history and at tag v4.0.0. [Validation notes](VALIDATION.md) distinguish software tests, known-case observations, gains and omissions; no raw datasets or generated reports are distributed here.

## 4.0.0 - 2026-10-15

Preserved baseline: clause-level fact checks, explicit rating reasons, consequential-use consistency, compact complete reports, and source/implementation attribution. The v4 skill files are unchanged from the local baseline.
